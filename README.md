# signals-lab · 信号与系统交互实验台

**打开即用的单文件 HTML**——《信号与系统》课程五个核心概念的交互实现。零依赖、离线可用、所有计算在浏览器本地完成。

控制实验台系列的第四件：[control-lab](https://github.com/Leslieryin/control-lab)（经典控制）、[modern-control-lab](https://github.com/Leslieryin/modern-control-lab)（现代控制）、[process-control-lab](https://github.com/Leslieryin/process-control-lab)（过程控制）之后，轮到信号与系统。

## 五个实验

| 实验 | 内容 | 交互 |
|---|---|---|
| **采样与混叠** | cos(2πf₀t) 以 fs 采样；频谱以 fs 周期延拓，欠采样时镜像落回带内 | 拖动 f₀ / fs，时域看「重建波完美穿过采样点但频率变了」、频域看镜像搬移；实时报告混叠频率 |
| **傅里叶级数** | 方波的谐波合成 (4/π)Σsin(nωt)/n | 拖动谐波数 N（1–99），看吉布斯过冲稳定在 8.95% 不消失；频谱条只含奇次谐波 |
| **卷积** | 翻转-平移-乘-累加的逐时刻展示 | 拖动当前时刻 t（或播放扫描），阴影面积 = y(t) 当前值；h 可选矩形/三角/RC 指数 |
| **RC 滤波器** | 一阶低通/高通的频域与时域 | 拖动 fc：幅频图自动标 −3.01dB @ fc 与 ±20dB/dec 渐近线，时域阶跃标 63.2%/36.8% @ τ |
| **AM 调幅** | 频谱搬移：载波 + 双边带 | 拖动 fc/fm/调幅度 m；m>1 高亮过调制警告；报告载波功率占比 |

## 已验证的数学锚点（浏览器实测 vs 教材公式）

- 吉布斯过冲：N=99 时实测 **9.0%**，理论 8.95%（跳变的比值恒定，N 增大不消失）
- 混叠频率：f₀=5kHz、fs=8kHz → 实测混叠 **3.0kHz** = |f₀−fs|，重建波逐点穿过采样点
- RC 低通：fc 处实测 **−3.01dB**（理论 −3.01）；阶跃 @τ 实测 **63.2%**（精确）
- AM：m=0.7 → 边带 **0.35** = m/2、带宽 2f_m、载波功率占比 80%
- 卷积：矩形(宽2)⊛矩形(T=1) 峰值 **1.000** = min(2,T)

## 实现说明

- 单文件 `index.html`（原生 JS + Canvas，无外部依赖）
- 频谱全部用**解析式**绘制（谐波条 / 镜像族 / 三根谱线），比截断 FFT 更精确且更适合教学
- 卷积用数值积分（步长 4ms），重建波形用解析混叠分量
- 采样实验刻意展示「重建波穿过所有采样点但频率错误」——这是混叠最反直觉、也最值得亲眼看到的一幕

## 适合谁

- 正在学《信号与系统》《数字信号处理》的本科生（采样/混叠、吉布斯、卷积、滤波器都是必考点）
